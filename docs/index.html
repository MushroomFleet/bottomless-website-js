Bottomless.js

A lightweight JavaScript library for creating infinite vertical scrolling experiences. Scroll seamlessly in either direction with content that loops indefinitely.

Get Started View on GitHub

Features

🔄 Infinite Scrolling

Create seamless vertical scrolling experiences in both directions. Content loops infinitely without visible breaks or jumps.

🧩 Zero Dependencies

Built with pure vanilla JavaScript (~5kb minified). No external libraries or frameworks required.

📱 Fully Responsive

Works perfectly on all device sizes from mobile phones to large desktop displays.

🌓 Theme Compatible

Seamlessly integrates with light/dark themes and other dynamic styling approaches.

🔌 Simple API

Easy to implement with minimal configuration. Offers customization options for advanced use cases.

🚀 Performance Optimized

Efficiently manages DOM elements to ensure smooth scrolling even during extended browsing sessions.

Installation

Direct Download

Download the latest version and include it in your project:

<!-- Add to your HTML file -->
<script src="path/to/bottomless.min.js"></script>

CDN

Include directly from a CDN:

<!-- Latest version -->
<script src="https://cdn.jsdelivr.net/gh/username/bottomless@latest/dist/bottomless.min.js"></script>

npm

Install via npm and import into your project:

# Install package
npm install bottomless-js

// Import in your JavaScript
import Bottomless from 'bottomless-js';

Basic Usage

Initialize with your content container:

const bottomless = new Bottomless({
    contentSelector: '.page-content',
    showPageIndicator: true,
    onPageChange: function(pageNum) {
        console.log('Now viewing page:', pageNum);
    }
});
