A lightweight JavaScript library for infinite scrolling

What is Bottomless.js?

Bottomless.js creates an infinite vertical scrolling experience where users can scroll endlessly in either direction, with the page content seamlessly looping.

Key Features

  • Infinite vertical scrolling in both directions
  • No dependencies, pure vanilla JavaScript
  • Easy to integrate with any website
  • Fully responsive for all device sizes

How It Works

As you scroll down, the page content is dynamically cloned and positioned to create the illusion of infinite content. When you reach the end of the original content, you seamlessly transition back to the beginning.

Try It Out

Keep scrolling down to see how the page repeats. Notice how the transition is smooth and seamless. You can also scroll up indefinitely!
